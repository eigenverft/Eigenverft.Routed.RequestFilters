# Eigenverft.Routed.RequestFilters

`Eigenverft.Routed.RequestFilters` is a preview ASP.NET Core library for request filtering, request controls, diagnostics, and supporting hosting utilities.

## Installation

```shell
dotnet add package Eigenverft.Routed.RequestFilters
```

## Target frameworks

The NuGet package provides assets for .NET 6, 7, 8, 9, and 10 and uses the ASP.NET Core shared framework.

## Included areas

- Request filtering by host, path, protocol, HTTP method, user agent, language, IP address, CIDR range, and related request properties.
- Request throttling, rate smoothing, logging, redirects, health-probe handling, and filtering evaluation.
- Supporting configuration, event storage, deferred logging, certificate, hosting, and application-directory utilities.

## Status

This project is pre-1.0. APIs and configuration may change between releases.

The first public preview is published through the repository's `main` branch CI/CD workflow.
